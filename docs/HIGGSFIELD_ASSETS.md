# Higgsfield asset pipeline (when credits are available)

The connected Higgsfield workspace currently reports **0 credits**. Until you start the [MCP Plus trial or add credits](https://checkout.stripe.com/) (see `show_plans_and_credits` in chat), the repo ships **procedural** scroll film and GLB generated by `scripts/generate-hero-assets.py`.

## Scroll-scrub film (`website_id`: `34e7e384-1e63-484d-8b21-32cf4d35fbac`)

1. **Storyboard** — `generate_image` with `soul_cinematic`, 16:9, six-panel grid, one continuous move (see `references/scroll-scrub.md` in website-builder-flow).
2. **Film** — single `generate_video` with `cinematic_studio_3_0` (or `cinematic_studio_video_v2`):
   - `aspect_ratio`: `16:9`
   - `duration`: 15 (max supported)
   - `resolution`: `1080p`
   - `generate_audio`: `false`
   - Storyboard as `medias: [{ value: <storyboard_job_id>, role: "image" }]` — **not** `start_image`
3. **Encode** — copy `scroll-scrub-video.sh` from the website-builder bundle, then:

```bash
bash /tmp/scroll-scrub-video.sh desktop source.mp4 app/public/assets/world/scene-01.mp4
bash /tmp/scroll-scrub-video.sh mobile  source.mp4 app/public/assets/world/scene-01-mobile.mp4
bash /tmp/scroll-scrub-video.sh poster  app/public/assets/world/scene-01.mp4 app/public/assets/world/scene-01-poster.png
bash /tmp/scroll-scrub-video.sh poster  app/public/assets/world/scene-01-mobile.mp4 app/public/assets/world/scene-01-mobile-poster.png
```

4. Update `app/design-brief.md` journey line, `website_repo_access` push, `deploy_website`.

## Next.js hero GLB

1. `generate_image` — sculptural ceramic on charcoal, 3:4, `soul_cinematic`.
2. `generate_3d` — `image_to_3d`, `should_texture: true`, `target_polycount: 30000`, image role `image`.
3. Download GLB → `public/studio/atelier-form.glb` (replace procedural file).

Regenerate procedural fallbacks anytime:

```bash
python3 scripts/generate-hero-assets.py
```
